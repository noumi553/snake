# 🐍 Snake Game

A classic Snake Game built from scratch for fun and learning! Control the snake, eat the food, and try to survive as long as you can without hitting the walls or yourself.

- 🍎 Random food generation
- 📈 Score tracking
- 💥 Collision detection (self & walls)
- 🎨 Retro-styled graphics
- 🕹️ Keyboard controls (Arrow keys / WASD)
